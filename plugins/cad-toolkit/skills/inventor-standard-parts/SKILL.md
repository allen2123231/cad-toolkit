# Inventor 標準件

先取得零件種類、標準編號、尺寸、長度、材料及用途；缺少會改變幾何的資料時詢問使用者。

優先檢查使用者現有 Content Center 或已知零件檔。需要自建時，從使用者提供的尺寸表或可靠標準資料取得尺寸，記錄所用版本；不得憑記憶捏造 DIN／ISO 數值。

確認 MCP 現有工具。以參數化草圖、旋轉、擠出與孔等功能建立所需幾何；螺紋可依需求採用表示性外觀或真實幾何，交付時明確說明。

在組合中放置前確認目標組合文件、數量、方向與配合面。驗證孔徑、長度、干涉與數量，避免修改其他組合零件。COM 長度以公分處理，高階 MCP 尺寸依工具說明採毫米。
