# 跨軟體 CAD 交接

先確認來源文件、目標軟體、輸出用途與要保留的資料：二維圖面、封閉實體、組合結構或參數特徵。

依用途選 DWG／DXF 或 STEP 等雙方支援格式，確認實際可用匯出工具。中性格式通常不保留原始參數特徵；不得把匯入實體描述成原生參數建模。

記錄來源單位、座標系、物件數量與尺寸。用新檔交接，保留來源文件；檔名與路徑依使用者指示，避免覆蓋其他版本。

匯入後讀回單位、包圍盒、數量及幾何有效性；實體用途須確認封閉。失敗時回報在哪一步與哪些資料不一致，不靠自動縮放掩蓋單位問題。

當某套 MCP 未安裝或未連線時，說明目前可完成的階段及安裝管理程式中的對應元件，不假設三套工具全部可用。
