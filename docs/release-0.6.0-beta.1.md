# MCP Toolkit 0.6.0-beta.1 — Beta 1：穩定的背景狀態更新

本版為未簽章 Beta 測試版，依使用者本次要求發布到 Beta 自動更新通道。後續版本預設仍受程式簽章發布門檻限制。Windows Smart App Control／SmartScreen 可能阻擋安裝或載入；本版不宣稱通過 SAC 相容性驗收，也不要求關閉 Windows 保護。

已安裝 Toolkit 的使用者可開啟「接收 Beta 測試版更新」，再按「檢查更新」與「立即更新」，沿用原位置並保留設定。手動安裝時請將 `McpToolkitSetup.exe` 與 `cad-toolkit-payload.zip` 放在相同資料夾。

## 修正

- 修正 MCP 管理每隔數秒在「重新檢查／檢查中…」之間切換與畫面跳動：背景監控只原地更新連線狀態，不重建卡片與導覽，保留捲動位置。
- 只有使用者手動重新檢查時才顯示「檢查中…」，單項檢查不會切換其他軟體的按鈕文字。按鈕保留固定的最小寬度，避免文字切換影響排版。
- 安裝、解除安裝、版本或名稱改變時，清單與分類數量仍會同步更新；連線失敗與恢復也會即時反映。

## 保留功能

- MCP 管理使用「已安裝／加入新 MCP」卡片網格，支援修復、重新檢查與單項解除安裝。
- 更新前需要關閉 CAD 時，顯示醒目的黃色提示框；不會自動關閉軟體與工作文件。
- Toolkit 更新沿用安裝位置並保留設定、MCP 啟用狀態、視窗名稱及紀錄。

本版仍延續既有 CAD 支援範圍；AutoCAD LT 2027 的實機驗收限制見驗證紀錄。這些介面修正會在更新完成後生效，舊版更新途中仍使用原本介面。
