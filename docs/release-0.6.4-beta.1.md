# MCP Toolkit 0.6.4-beta.1 — Rhino 單一系統匣整合

本版為未簽章 Beta 測試版。Windows Smart App Control／SmartScreen 可能阻擋安裝或載入；不宣稱通過 SAC 相容性驗收，也不要求關閉 Windows 保護。後續版本仍維持既有簽章發布門檻。

## 如何更新

請先儲存並關閉已安裝 MCP 對應的 CAD 軟體，再到 Toolkit「設定與更新」啟用「接收 Beta 測試版更新」，按「檢查更新」與「立即更新」。原安裝位置、設定及啟用政策會保留。更新後重新開啟 Codex，讓對話載入新版 Plugin。

本次 Rhino 原生外掛與 Python 服務成套更新為 Toolkit 管理版 0.5.4。不要只替換 Toolkit EXE；完整更新後再開啟 Rhino，就會自動連線，不需要輸入 mcpstart 或拖入 RHP。

手動更新時，將 `McpToolkitSetup.exe` 與 `cad-toolkit-payload.zip` 放在同一資料夾後執行安裝程式。只下載 EXE 且不能連網取得 payload 時，無法完成安裝。版本 0.6.4-beta.1 高於本機測試版 0.6.3-dev.1，測試機也能收到此版。

## Rhino 修正

- **系統匣只保留 MCP Toolkit**：由 Toolkit 安裝的 Rhino 外掛不再啟動額外的 RhinoMCPTray.exe，管理套件也不再封裝該程式。
- **Rhino 單獨開啟也不會多出圖示**：以套件內的持久標記辨識 Toolkit 管理模式，不依賴環境變數或 Toolkit 當下是否正在執行。
- **自動連線與視窗綁定保留**：原生服務、端口分配、執行個體／文件識別、狀態回報與每個對話的 binding_id 都保留。系統匣介面不是連線服務本身，移除它不會停止 Rhino MCP。
- **原狀態入口改開 Toolkit**：Rhino 的原生狀態視窗入口會開啟 MCP Toolkit 的 MCP 管理頁；已有管理程式時使用同一個，不會建立第二個系統匣。找不到管理程式時提供清楚提示，不再要求開啟已移除的 Tray。
- **處理舊版殘留程序**：僅在 Rhino 已關閉後替換外掛；如舊 Tray 仍存活，只處理已核對為該 RhinoMCP 套件目錄內的確切 GUI 程序，不依同名程序批次結束，也不強制關閉 CAD。
- **獨立版行為保留**：非 Toolkit 管理模式的 RhinoMCP 仍可建置自己的系統匣；此修正不會以全域設定關閉其他安裝。

## 驗證與範圍

- 175 項 Python、32 項桌面介面、28 項更新／清理、8 項共用 C# 管理模式及 4 項打包後 Rhino 連線守衛測試通過。
- 在兩個真實 Rhino 8 視窗完成 22 項驗收：自動連線、不同視窗獨立綁定、各自建立及讀回物件、第三個連線不能占用既有視窗、管理程式重啟後綁定仍可使用。
- 測試過程與結束後均沒有 RhinoMCPTray 程序；重複開啟狀態介面仍只有一個 Toolkit。測試物件已移除，沒有修改使用者文件。
- 管理模式套件已檢查標記存在且不含 Tray EXE；獨立模式也完成建置，保留 Tray 並不帶管理標記。
- 本機使用者已確認可用，授權本次合併與發布。

AutoCAD／Inventor 的上游套件版本及操作方式沒有變更。中斷恢復與舊指令不重播的既有保護繼續保留。
