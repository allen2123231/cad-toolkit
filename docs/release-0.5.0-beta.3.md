# MCP Toolkit 0.5.0-beta.3 — 檢查回饋與 Rhino 舊版修復

本版為本機／CI 測試修正版。未簽章的公開發布門檻維持啟用，不宣稱相容 Smart App Control；不關閉 Windows 保護功能。

## 介面

- 合併「Toolkit 更新」與「MCP Toolkit」為單一卡片，集中目前版本、更新狀態、檢查更新、安裝／加入 MCP 及發布頁連結。
- 「重新檢查」立即顯示檢查中並暫停重複點擊，完成後顯示檢查時間。檢查進行中收到的手動要求會接續執行。
- 手動檢查先更新視窗清單，清除這次元件的啟用重試等待；若成功啟用，立即讀回新狀態。
- 檢查失敗時保留原本已安裝清單，顯示「檢查失敗」及原因，避免看起來未安裝或沒有反應。

## Rhino 舊版

- 安裝前逐檔比對既有外掛；完全相同時沿用。
- 需要替換時先確認 Rhino 已關閉，再將舊 RhinoMCP 版本目錄移到備份，避免同版本舊檔／不完整套件阻擋安裝。其他 Rhino 外掛不變。
- Rhino 安裝工具結束後再次逐檔驗證。安裝失敗或驗證失敗會移出不完整的新檔，還原原外掛。
- 舊外掛仍被占用時提供關閉 Rhino 的明確提示；備份失敗時不繼續安裝。原檔及失敗的新檔會保留供檢查。
- 即使套件已存在，若目前 Rhino 仍載入舊版，仍會提示重新開啟 Rhino。
- 修正同一 Rhino 版本有多份舊安裝紀錄時，解除安裝可能先被舊紀錄擋住的問題。

## 舊安裝與設定

- 安裝程式沿用偵測到的原位置，包括舊 `CadToolkit` 資料夾，保留設定。
- JSON 設定寫入加入短暫檔案鎖重試；介面讀取允許安全替換，減少舊程式讀檔造成的安裝失敗。
- 沿用 Beta 2 的單項重裝修正，保留其他 MCP 的環境與啟用設定。

## 驗證

Python 測試涵蓋舊版與同版本不同內容、安裝失敗還原、假成功驗證、檔案占用、其他外掛保留及短暫設定鎖。WPF 檢查使用可控制的非同步診斷程序，驗證立即回饋、排隊檢查、完成時間與失敗清單保留。

隔離測試不修改使用者的 Rhino 外掛。實際更新會先要求儲存並關閉 CAD，保留原安裝位置與設定。安裝後重新開啟 Codex 以載入更新後的工具。
