# MCP Toolkit 0.5.0-beta.2 — 單項重裝修正版

本版本先提供本機／CI 測試，沿用儲存庫的程式簽章門檻；尚未取得可信任簽章前不公開發布安裝包，也不宣稱相容 Smart App Control。

## 修正內容

- 單項安裝／重裝不再覆蓋其他 MCP 的安裝位置。每個元件分別記錄已準備的環境，與最後一次安裝工作及目前啟用的版本分開。
- 等待啟用的 AutoCAD、Inventor、Rhino 都使用各自正確的環境；安裝其中一套後，其餘兩套的工具清單不會消失。
- 安裝中途失敗時，保存每個已完成的元件，完成其連線設定與工具註冊後回報失敗項目。使用者明確取消時停止後續設定，保留可續作的環境。
- 偵測舊版單項重裝留下的成功安裝紀錄，將被漏列的元件恢復為已安裝；這個復原不會擅自啟用或執行 CAD 操作。
- 重裝與啟用一套 MCP 時，不重新啟用其他被停用的元件。
- 更新、啟用、解除安裝及部分成功後的管理介面，均使用各元件的獨立紀錄。

## 使用方式

不需要清除全部安裝，也不需要重裝另外兩套。儲存並關閉 CAD 後，以本修正版安裝到原本 Toolkit 位置，保留既有設定；完成後重新開啟 Codex。之後可從「安裝與版本」只修復失敗的元件。

## 已驗證

- 90 項 Python 測試，包含單項重裝、舊紀錄恢復、等待啟用的元件、失敗保留與停用政策。
- D 槽中文路徑實際安裝三套環境，模擬 Rhino 原生外掛設定失敗後只重裝 Rhino；AutoCAD／Inventor 的路徑與啟動檔雜湊不變，三套產生的 MCP 服務均可啟動，工具數為 10／38／78。
- 上述整合測試使用私有 Codex 設定，實際註冊及移除 Plugin；使用者原設定雜湊不變，沒有啟動或修改 CAD。原生 Rhino 失敗屬模擬，未以此測試改動使用者外掛。
