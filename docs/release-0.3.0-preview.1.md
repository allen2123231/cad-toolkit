# MCP Toolkit 0.3.0-preview.1

本版以新的 Windows 常駐管理介面取代舊八步精靈。

- 系統匣插頭標誌、小型 MCP 狀態面板及完整管理視窗。
- 顯示三套軟體的實際文件、連線方式／端口、安裝狀態及 Toolkit 相容版本。
- 安裝流程：選擇 MCP → 安裝環境與自動連線套件 → 開啟軟體後自動檢查、啟用。不需另行安裝 Plugin 或輸入啟動指令。
- Rhino 多實例以 PID、程序建立時間、文件與端口選取；新 MCP 對話套用目標，不猜測其他視窗。
- AutoCAD 使用每份文件自動載入的 ApplicationPlugins 套件，不改 SECURELOAD／TRUSTEDPATHS。
- Inventor MCP 以現有應用程式自動附加，避免透過 COM 冷啟動；使用者從 Toolkit 開啟正常 Inventor。
- 真實指令紀錄：工具名稱、時間、執行結果與耗時。只保存在本機，不保存參數、提示詞或完整輸出。
- 可選擇 Windows 登入時啟動、個別 MCP 安裝／修復、還原及解除設定。

固定組合：AutoCAD MCP 3.2.0、RhinoMCP 0.5.2、Inventor MCP 0.1.0。相容版本不等於各上游的網路即時最新版。

## 驗證範圍

- 51 項 Python 測試通過，包含訊息轉送、錯誤結果、本機紀錄、版本狀態、自動附加及多實例識別。
- 新 WPF 介面 19 項檢查，管理視窗四頁的 96／144／192 DPI 渲染，加上新安裝視窗、系統匣面板及原生圖示。
- 七種元件組合的實際隔離安裝、重複安裝與中斷續裝通過，未修改使用者 Codex 設定。
- AutoCAD 2026：安裝自動載入套件後，以正常啟動及毫米空白範本開啟；禁止 MCP 服務補載 dispatcher，仍能透過 file_ipc 讀圖，檢查前後文件狀態相同。
- Inventor 2027.1：正常啟動後，新的 Toolkit MCP 第一個工具直接呼叫 status 即自動連線，沒有先呼叫 connect；首頁無文件。
- Rhino 自動啟動的原生外掛仍固定為已驗證的 0.5.2；本版沒有更換其原生二進位檔。

本版未以新 UI 完成乾淨 Windows、真人新手測試或所有 CAD 版本驗收。Toolkit EXE 尚未簽章。授權、登入及企業外掛政策提示仍可能需要使用者處理。

本次應用程式測試使用空白範本或唯讀查詢，沒有修改工作圖面。AutoCAD 測試文件與測試載入套件已清理，Inventor 保留正常首頁。
