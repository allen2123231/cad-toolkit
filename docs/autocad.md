# 安裝 AutoCAD 自動連線

在新安裝介面選擇 AutoCAD MCP，程式會自動完成連線設定。

## 操作位置

完整管理 → 安裝與版本 → 安裝／修復 AutoCAD MCP

已驗證 AutoCAD 2026 每份圖面的自動載入與 file_ipc 讀圖；其他版本未驗證。

## 依序操作

### 1. 安裝 AutoCAD MCP

操作位置：完整管理 → 安裝與版本 → 安裝／修復 AutoCAD MCP

在安裝與版本頁選擇 AutoCAD MCP，按「安裝所選 MCP」。必要環境、外掛及 AI 工具設定一起完成。

完成後：必要環境與連線設定已準備。

### 2. 開啟 AutoCAD

操作位置：Toolkit 的「開啟 AutoCAD」

開啟 AutoCAD。若安裝時已開啟，請先自行儲存並重開一次，再開啟要使用的文件。

完成後：軟體已正常開啟；授權／登入確認完成。

### 3. 自動連線

操作位置：右下角 MCP Toolkit 狀態面板

查看右下角 MCP Toolkit 狀態。檢查通過後自動啟用；到 Codex 開啟新對話即可使用。

完成後：檢查顯示橋接已連線、目前圖面名稱。詳細資料的 backend 必須是 file_ipc；只有工具程序啟動不算成功。


## 完成後會看到

檢查顯示橋接已連線、目前圖面名稱。詳細資料的 backend 必須是 file_ipc；只有工具程序啟動不算成功。

## 常見問題

- 找不到軟體：先安裝自己的 AutoCAD 並完成合法授權。
- 尚未連線：在安裝與版本頁按安裝／修復；若外掛正在使用，先自行儲存並重開軟體。
- 多個視窗：Rhino 可在管理視窗選擇目標；其他軟體請先確認唯一目標。Toolkit 不會替你關閉文件。

## 自選練習：AutoCAD：一個矩形

在 AutoCAD 使用新增圖面建立空白練習檔，單位選毫米。不要切回工作圖面。

貼到 Codex：

> 先確認目前是我新建的空白練習圖面，單位為毫米；如果不是請停止。在原點建立寬 100 mm、高 60 mm 的封閉矩形，讀回尺寸確認。不要修改其他文件，也不要自動儲存。

預期結果：只有一個 100 × 60 mm 矩形，AI 回報尺寸與目前練習圖面。

確認結果後，使用 AutoCAD「另存新檔」存成 CAD練習_矩形.dwg。
