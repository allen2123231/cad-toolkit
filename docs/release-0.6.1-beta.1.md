# MCP Toolkit 0.6.1-beta.1 — AutoCAD 中斷恢復與受控連線

本版為未簽章 Beta 測試版，依使用者本次要求發布到 Beta 自動更新通道。後續版本預設仍受程式簽章發布門檻限制。Windows Smart App Control／SmartScreen 可能阻擋安裝或載入；本版不宣稱通過 SAC 相容性驗收，也不要求關閉 Windows 保護。

## 更新方式

請先儲存並關閉已安裝 MCP 所對應的 CAD 軟體，再到 Toolkit「設定與更新」啟用「接收 Beta 測試版更新」，按「檢查更新」及「立即更新」。更新沿用原安裝位置並保留設定。AutoCAD 原生橋接也會一起更新，重新開啟 CAD 後自動載入，不需要 APPLOAD 或手動輸入連線指令。

手動安裝時，將 `McpToolkitSetup.exe` 與 `cad-toolkit-payload.zip` 放在相同資料夾後執行安裝程式。只下載 EXE 而無法連網取得 payload 時，不能完成安裝。這些變更會在更新完成後生效，舊版更新途中仍使用原本介面。

## AutoCAD 中斷恢復

- CAD 在指令中途關閉、回覆逾時、通知失敗，或原生指令停在等待輸入時，保留上一批的結果不明紀錄。
- 新要求仍可收到。恢復期間的繪圖要求會明確回覆「未執行」，不會保存成稍後自動補送的工作。
- Toolkit 自動顯示中斷恢復面板，提供開啟軟體、重新檢查及目前圖面名稱、位置與單位。儲存可保留的工作並重新開啟 CAD，檢查圖面後勾選確認，才可繼續新操作。
- 確認只解除暫停。上一批與暫停期間被擋的操作都不會自動重送；請回對話明確提出後續操作。
- 舊唯讀 ping 僅在安全條件成立時封存；不依檔案年齡清除不明修改。

## 通訊與執行保護

- 通知移出 MCP 主流程，避免完整版 AutoCAD 的 COM 通知呼叫卡住整個服務。等待 CAD 啟動時，恢復查詢仍可回覆。
- 核對程序、建立時間、主視窗與 LT 收件子視窗；原生端在執行前再次核對文件身分、協定及恢復屏障。通知遲到時也不能執行過期工作。
- AutoLISP 回報文件、忙碌及接手／執行／完成／等待輸入階段。Reactor 僅觀測狀態，不在回呼中畫圖，也不自動 ESC 取消操作。
- 正確辨識已終止但仍被其他程式持有控制代碼的 Windows 程序，避免中斷後繼續等完整逾時。
- 通道占用時背景檢查讓路；最近指令區分「已中斷」與「未執行」。未導入會自動補做繪圖的佇列。
- 舊原生外掛缺少識別保護時提示需要更新，不回退到無身分檢查方式。

## 測試與範圍

- 146 個 Python 回歸測試、32 項一般桌面檢查、8 項恢復面板檢查通過。
- 獨立 AutoCAD 2026 程序完成 27 項原生實機檢查，包括部分畫圖後關閉、重開確認、通知遲到、延遲回覆、通道占用及 LINE 等待輸入。測試保留原有使用者 CAD 視窗。
- 實機重開後只保留原有 1 個圓，明確送出新操作後才增加為 2 個圓。通知遲到及被擋的工作沒有增加圖形。本次關閉偵測約 1.28 秒，並非所有電腦的時間保證。
- 實機使用完整 AutoCAD 2026 搭配 Windows 訊息測試共用原生橋接，不代表 LT 2027 或完整版 COM 派送已完成完整實機驗收。LT 專用通知分支、無外部 COM 限制與故障處理有自動測試；仍需 LT 2027 電腦驗證安裝、自動載入及完整操作。
- AutoCAD 仍要求唯一明確目標，尚未支援不同對話各自綁定多個 AutoCAD 視窗。中斷恢復不會救回尚未存檔的工作，也不代表任意 LISP 具有整批回滾能力。

更新不會自動關閉使用者 CAD，也不會為了檢查連線而自動重送上一批繪圖。
