# MCP Toolkit 0.6.5-beta.1 — AutoCAD 跨圖面中斷恢復

本版為未簽章 Beta 測試版，依維護者對本版的明確授權公開至原測試群的 Beta 自動更新來源。Windows Smart App Control／SmartScreen 可能阻擋安裝或載入；不宣稱通過 SAC 相容性驗收，也不要求關閉 Windows 保護。後續版本的可信任簽章發布門檻維持不變。

## 更新改善

- 修正 AutoCAD 中斷後，切換到另一份圖面時按「檢查並恢復連線」無法繼續的問題。同一個 AutoCAD 主視窗內，可從目前作用中的圖面完成檢查，不必為了恢復連線而關閉 AutoCAD。
- 檢查所有開啟文件的忙碌狀態，核對程序、視窗、文件與切換紀錄，隔離及撤銷舊要求；上一批結果不明的指令不會自動重送或補執行。
- 恢復面板同時顯示「中斷時圖面」與「目前圖面」。檢查後仍須由使用者確認圖面，才解除修改暫停；檢查後再次切換圖面，先前的確認會失效。
- 唯讀查詢不會解除修改保護；新修改要求不會偷偷排隊，確認後需重新提出。
- 恢復失敗原因保留在面板內，不再因背景狀態更新而消失。
- 在「設定與更新」加入公開 Roadmap 入口，可直接查看工作進度與提交想法。

## 如何更新

從 0.5.0 或其他已支援自動更新的版本，先儲存並關閉已安裝 MCP 對應的 CAD 軟體，到 Toolkit「設定與更新」（舊版可能顯示「安裝與版本」）啟用「接收 Beta 測試版更新」，再按「檢查更新」及「立即更新」。更新會沿用安裝位置並保留設定，完成後重新啟動 Codex，讓對話載入新版 Plugin。

本次 AutoCAD 橋接必須與 Toolkit 成套更新，請勿只替換 EXE。重新開啟 CAD 後會自動載入，不需 APPLOAD 或手動輸入連線指令。恢復連線可不關閉 AutoCAD，與安裝時為替換外掛需先關閉 CAD 是不同流程。

若舊版無法取得更新，請從本頁同時下載 `McpToolkitSetup.exe` 與 `cad-toolkit-payload.zip`，放在同一資料夾後執行安裝程式，沿用原安裝位置。

## 驗證與範圍

跨圖面恢復已有 37 項真實 AutoCAD 2026 測試證據，涵蓋文件切換、指令忙碌、部分修改後關閉、重新開啟、遲到回覆與通知、舊要求撤銷、唯讀及修改保護。發布前另通過 182 項 Python、32 項桌面介面、12 項恢復面板及 28 項更新／解除安裝檢查，並核對安裝包及 payload 雜湊。

AutoCAD LT 2027 的既有偵測、啟動與自動載入支援保留；完整 AutoCAD 的實機測試不能代替 LT 2027 實機驗收。本版不包含室內設計／SketchUp、新群組管理客戶端或測試分支的新功能。Rhino 單一系統匣與既有自動連線、視窗綁定保持保留。
