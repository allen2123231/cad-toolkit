# 真實截圖素材

這些 PNG 用於安裝程式與 GitHub 教學，沒有生成式重繪、補字或放大重建。

| 檔案 | 來源與公開處理 |
|---|---|
| autocad-command.png | 本機 AutoCAD 2026 指令列原圖 |
| autocad-appload.png | 本機 AutoCAD 2026 載入應用程式對話框原圖 |
| autocad-success.png | 使用者提供的成功訊息原圖 |
| inventor-home.png | 使用者提供的 Inventor 2027.1 首頁；僅保留原圖 x=0、y=150、237×290 的左側區域 |
| rhino-input.png | 使用者提供的圖 1；移除頂端 22 像素的工作文件標題列 |
| rhino-result.png | 使用者提供的圖 2；移除頂端 22 像素的工作文件標題列 |

裁切保持原始像素，另存無損 PNG。未公開帶有帳號、最近文件清單及工作文件標題的完整來源圖。

Rhino 圖 1 上方包含先前套件管理器的歷史訊息，用於辨識 mcpstart 輸入位置，不作為連線成功證據。成功訊息與 Toolkit 的唯讀診斷分開確認。
