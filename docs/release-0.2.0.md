# CAD Toolkit 0.2.0-preview.1

這個版本將安裝與日常使用改為新手導向的繁體中文介面。

## 下載

下載 `CadToolkitSetup.exe` 後開啟。離線安裝時，另下載同版 `cad-toolkit-payload.zip`，放在 EXE 旁。

## 新功能

- 七步首次設定精靈，記住軟體選擇與未完成步驟。
- 日常首頁分別顯示三套 CAD 的檢查結果、文件與時間，提供對應下一步。
- AutoCAD、Inventor、Rhino 與 Codex 離線圖解、複製指令及檔案位置按鈕。
- 第一次唯讀檢查，以及另建練習文件的三種自選範例。
- 元件安裝進度、下載取消、安裝安全停止與完成元件續做。
- 將技術紀錄收進詳細資料，更新、還原與解除安裝分開管理。

## 修正

- 診斷正常結束但未連線時，不再顯示通用的成功訊息。
- Inventor 未開啟文件不會被視為可以使用。
- 未啟用工具與連線失敗分開顯示，逐套啟用需再次通過檢查。
- 重新開啟不沿用歷史連線成功；檢查結果標記時間與適用版本。

## 升級

舊版使用者可直接執行新 EXE，或從舊版檢查新版下載。新環境先並存，驗證後逐套啟用。保留 `state.json`、舊版本及設定備份。載入中的 Rhino 外掛由使用者自行保存工作並重新啟動後處理。

## 仍待驗收

乾淨 Windows、七種組合的完整 GUI 安裝、AutoCAD／Rhino 外掛全流程、Inventor 建模練習、Codex 新對話載入新版、真實 100%／150%／200% DPI 操作及真人新手可用性測試。已完成的程式驗證詳見儲存庫 [驗收紀錄](https://github.com/allen2123231/cad-toolkit/blob/main/docs/validation.md)。

本版仍是預覽版；不宣稱以上項目已全部通過。舊版 `0.1.0-preview.1` 繼續保留下載。
