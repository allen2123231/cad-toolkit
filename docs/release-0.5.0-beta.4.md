# MCP Toolkit 0.5.0-beta.4 — 更新回應與階段進度

本版目前供本機／CI 驗證，尚未公開發布。Beta 3 的未簽章公開發布例外不自動延伸到此版。

- 下載套件、下載安裝程式與開啟更新視窗分開標示；有下載長度時顯示當前檔案進度，驗證、解壓及元件程序等待使用活動進度條，不虛構整體完成百分比。
- 顯示已耗時間，持續更新；較久未收到進度時顯示等待狀態與查看詳細資料提示。
- 下載回報最多約每半秒一次，直接更新現有卡片；避免每個資料區塊都重建整個管理視窗。
- 舊 Toolkit 程序檢查／結束及已驗證套件複製移到背景，先讓更新視窗繪製；CAD 文件不會被強制關閉。
- 支援取消下載。連續 45 秒未取得回應或資料時中止下載並說明重試，刪除不完整下載，保留原版本及設定。
- 獨立安裝視窗顯示活動進度、目前元件訊息、已耗時間及詳細資料；尚未有元件回報時也可分辨介面仍有回應。
- 更新時的 Codex 設定替換也採短暫檔案鎖重試，避免讀取程式或掃描造成間歇性失敗；先保留原設定再替換。

驗證包含高速串流下的回報頻率、停滯下載時的 WPF 介面與計時更新、取消後不啟動安裝程式、無資料逾時及原有更新／清除測試。未在使用者回報問題的另一台電腦重現完整安裝，不宣稱所有卡死原因均已排除。
