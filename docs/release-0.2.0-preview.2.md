# 0.2.0-preview.2：完整新手流程與真實截圖

這次將已確認的 UI／UX 設計套用到 Windows WPF 安裝管理程式。從首次設定到日常維護均使用實際安裝與診斷後端，沒有模擬成功狀態。

## 本次改動

- 淺色綠系介面、側邊導覽、獨立更新與問題處理頁；小視窗保留上方導覽與下方操作。
- 八步首次設定：歡迎 → 選擇軟體 → 準備 AI 助手 → 安裝連線工具 → 設定 CAD → 安裝 Plugin → 確認可以使用 → 第一次使用。
- AutoCAD 三步：APPLOAD、選檔並載入、確認成功訊息。
- Inventor 一步：開啟並停留首頁即可；唯讀 COM 檢查確認應用程式後，無文件也能啟用。建模時才需要正確文件。
- Rhino 兩步：開啟並輸入 mcpstart、確認啟動結果；首次外掛註冊收在獨立說明。
- 使用真實截圖，提供原尺寸查看；公開素材已裁除帳號與工作檔名。
- Plugin 安裝獨立呈現；新元件保持停用，通過診斷後才逐套啟用。
- 保存教學頁次、中斷狀態與登入確認；自動遷移舊版精靈步驟，保留原安裝狀態與備份。
- 更新、還原與解除安裝明確顯示影響範圍；不自動關閉 CAD。

## 下載與使用

下載 `CadToolkitSetup.exe` 開啟。需要離線安裝時，同時下載本版本 `cad-toolkit-payload.zip`，與 EXE 放在同一資料夾。

已有版本可從「檢查新版」準備新版。安裝完成後，依教學檢查並逐套啟用；原有可用版本保留。

## 驗證與限制

已執行後端單元測試、WPF 配置／渲染與下載錯誤測試，以及七種組合的隔離後端安裝。詳細項目見 [驗收紀錄](validation.md)。

**仍為預覽版。** 乾淨 Windows、三套 CAD 完整 GUI 流程、Codex 新對話、實體螢幕 DPI 與真人新手測試尚未全部驗收。安裝程式尚未簽章。其他 CAD 版本未驗證。

解除安裝保留版本檔案及備份；還原處理 MCP 連線設定，Rhino 外掛的重新註冊仍需按圖解操作。
