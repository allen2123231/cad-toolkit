# MCP Toolkit 0.5.0-beta.6 — MCP 管理與設定更新整合

本版目前供本機／CI 測試，尚未公開發布。

- 左側導覽統一為「MCP 狀態、MCP 管理、最近指令、設定與更新」。Toolkit 主程式更新與通知偏好集中在「設定與更新」，更新通知及舊入口也導向同一頁。
- 更新說明使用原生 Markdown 排版，呈現標題、粗體、清單、行內程式碼、程式碼區塊、表格與網站連結；不再把 `#`、`**`、反引號等格式字元直接顯示。網頁腳本不會執行，圖片不會自動連線載入，只有 HTTP／HTTPS 連結可由使用者點擊開啟。
- 主視窗與系統匣的 MCP 狀態只列出已安裝元件，包含未開啟軟體與連線異常的已安裝元件。沒有已安裝元件時提供管理入口。
- 原元件安裝卡片移至「MCP 管理」，以「已安裝／未安裝」分類並顯示數量。已安裝提供修復／重裝、重新檢查與連線設定；未安裝提供版本及對應安裝操作。
- 元件目錄取自版本清單並合併已偵測的元件，介面不再寫死三套軟體。新增元件仍需提供對應安裝與連線整合，未有處理程式時不顯示可用的安裝按鈕。
- 在設定頁閱讀更新說明時，背景 MCP 狀態刷新不會重建整頁，避免重置閱讀位置。

Markdown 使用 Markdig 1.6.0，授權文字見 `docs/third-party/Markdig-LICENSE.txt`，安裝程式亦內嵌副本。
