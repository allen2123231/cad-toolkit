# MCP Toolkit 0.5.0-beta.6 — MCP 管理與設定更新整合

本版為未簽章 Beta 測試版，依使用者本次要求發布到 Beta 自動更新通道。後續版本預設仍受程式簽章發布門檻限制。Windows Smart App Control／SmartScreen 可能阻擋安裝或載入；本版不宣稱通過 SAC 相容性驗收，也不要求關閉 Windows 保護。

已安裝 Toolkit 的使用者可開啟「接收 Beta 測試版更新」，再按「檢查更新」與「立即更新」，沿用原位置並保留設定。手動安裝時請將 `McpToolkitSetup.exe` 與 `cad-toolkit-payload.zip` 放在相同資料夾。

- 左側導覽統一為「MCP 狀態、MCP 管理、最近指令、設定與更新」。Toolkit 主程式更新與通知偏好集中在「設定與更新」，更新通知及舊入口也導向同一頁。
- 更新說明使用原生 Markdown 排版，呈現標題、粗體、清單、行內程式碼、程式碼區塊、表格與網站連結；不再把 `#`、`**`、反引號等格式字元直接顯示。網頁腳本不會執行，圖片不會自動連線載入，只有 HTTP／HTTPS 連結可由使用者點擊開啟。
- 主視窗與系統匣的 MCP 狀態只列出已安裝元件，包含未開啟軟體與連線異常的已安裝元件。沒有已安裝元件時提供管理入口。
- 原元件安裝卡片移至「MCP 管理」，以「已安裝／加入新 MCP」分類並顯示數量。兩個分類均採隨視窗寬度排列的卡片網格。已安裝提供修復、重新檢查與單項解除安裝；加入新 MCP 提供版本及對應安裝操作。
- 單項解除安裝會先確認範圍並備份設定，移除對應工具入口、Skills 與可驗證的自動連線外掛，保留其他 MCP、Toolkit、CAD 與工作文件。對應 CAD 未關閉時會停止；舊快取不會被重新辨識為已安裝。共用版本快取保留到完整解除安裝 Toolkit，既有 Codex 對話需重啟才能卸載舊工具。
- 元件目錄取自版本清單並合併已偵測的元件，介面不再寫死三套軟體。新增元件仍需提供對應安裝與連線整合，未有處理程式時不顯示可用的安裝按鈕。
- 在設定頁閱讀更新說明時，背景 MCP 狀態刷新不會重建整頁，避免重置閱讀位置。
