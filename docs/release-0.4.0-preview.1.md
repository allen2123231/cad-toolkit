# 0.4.0-preview.1：視窗命名與 Rhino 對話綁定

每段 Rhino 對話先在 Toolkit 彈出的面板選擇視窗，選定後自動繼續。視窗預設以 Rhino 01、Rhino 02 命名，也可以改成工作用途名稱；名稱同步顯示在軟體標題列，與文件名稱及 TCP 端口分開。

## 操作規則

- 每個 Rhino 視窗只接受一個 Toolkit 連線；轉交會等待目前指令完成，再撤銷舊連線。
- 切換文件後，修改操作需在 Toolkit 確認。確認不會重播先前指令；另存新檔不需要重新綁定。
- 關閉再開軟體不承接舊綁定；端口或 PID 重用也不能使舊對話操作新視窗。
- AutoCAD、Inventor 本版先提供獨立視窗清單、改名與定位，尚未開放多視窗對話路由。
- 視窗身分不符、外掛缺少保護協定時直接拒絕。指令送出後無法確認結果時不重播，該視窗需檢查、儲存並重開後才能重新連線。

## 安裝與升級

結束舊版 Toolkit，將同版 `McpToolkitSetup.exe` 與 `cad-toolkit-payload.zip` 放在同一資料夾後執行安裝。Rhino 外掛及 Python 服務配對為 0.5.3；如果安裝時 Rhino 已開啟，請儲存並重開，再到 Codex 開新對話。日常不需要輸入啟動指令或拖曳 `.rhp`。

新連線不使用舊的共用選窗設定。舊指令紀錄會保留；新增紀錄包含視窗及連線名稱，不記錄工具參數或完整結果。

## 驗證範圍

Windows 本機已驗證兩個新 Rhino 自動啟動橋接，經同一個 MCP 路由分別建立、讀回不同尺寸的封閉圓柱；換檔阻擋、確認不重播、另存保留綁定、跨視窗身分拒絕及轉交撤銷舊連線皆通過。AutoCAD 2026、Inventor 2027 各兩個主視窗的辨識、名稱與標題還原已通過，未在其工作文件執行建模指令。

實際發布格式的 EXE 已驗證由 MCP 要求自動彈出選窗面板，按下指定視窗的連線按鈕後回傳綁定；同一個 stdio 服務同時收到兩個連線的讀取要求，回覆與幾何範圍均正確。關閉測試 Rhino 後，以新程序重用同一端口，舊綁定及原生身分皆被拒絕。七種 MCP 組合也完成隔離安裝、重複安裝及中斷續裝，使用者 Codex 設定雜湊未改變。

66 項 Toolkit 自動測試、4 項打包後 Rhino 保護測試，以及 27 項 WPF 畫面與控制項檢查通過；畫面檢查使用示範資料，不等於真人可用性驗收。乾淨 Windows、其他 CAD 版本與 EXE 簽章尚未完成。

## 建置來源

Rhino 採固定上游 commit `6ad258efaa49086c1a7747506564802e84f8d0d7` 加上 `sources.json` 宣告並核對 SHA-256 的補丁。Python wheel 與原生 Yak 均從同一份修補後來源建置；不用依賴尚未發布的上游下載網址。AutoCAD、Inventor 固定來源與版本維持原測試組合。
