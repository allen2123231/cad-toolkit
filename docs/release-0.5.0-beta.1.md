# MCP Toolkit 0.5.0-beta.1 — Beta 測試版

這是 Beta 測試版，供驗證自動更新、通知與完整解除安裝。EXE 尚未簽章；乾淨 Windows、不同 CAD 版本及真人新手驗收尚未完成。

## 自動檢查與通知

- Toolkit 啟動時及每天背景檢查 GitHub Release；離線或查詢失敗不影響現有 CAD 連線。
- 有新版本時發出 Windows 通知，點擊開啟「安裝與版本」；系統匣面板會保留更新提示。若 Windows 關閉通知，仍可從面板查看。
- 同一版本不重複通知，提供「稍後提醒」「略過此版本」及手動「檢查更新」。
- 設定可關閉自動檢查、Windows 通知或 Beta 更新。Beta 版預設接收測試版本；正式版可使用穩定通道。

## 按一下更新並保留設定

- 「立即更新（保留設定）」下載並驗證安裝程式與離線套件，接著自動開始更新，不必重新挑選安裝位置或 MCP。
- 只更新已安裝的元件，保留原路徑、MCP 啟用／停用狀態、視窗名稱、指令紀錄與自動啟動設定。
- 更新前備份設定及舊程式；失敗時回復原啟用紀錄與設定。已下載的檔案未通過 SHA-256 驗證時不會執行。
- 請先儲存並關閉已安裝 MCP 對應的 CAD，避免替換載入中的外掛；程式不強制關閉 CAD。完成後重新啟動 Codex，讓新 MCP 工具生效。
- 安裝包從固定的 GitHub 儲存庫發布資產下載。發布必須包含 `McpToolkitSetup.exe`、`cad-toolkit-payload.zip`、`release-manifest.json` 與 `SHA256SUMS.txt`。

0.4.1 及更早版本尚未接入自動檢查，必須先手動安裝本 Beta 一次；之後的新版本才能從程式內收到通知並更新。

## 完整解除安裝

- 「設定 → 完整解除安裝 MCP Toolkit」，或 Windows 應用程式清單的解除安裝，會開啟清除範圍確認畫面。
- 移除此位置的 Toolkit、已安裝 MCP 環境、Toolkit Codex Plugin／marketplace、AutoCAD 自動連線套件、可驗證的 Rhino 外掛、捷徑與自動啟動。
- CAD 本體、工作文件、其他 MCP／外掛及來源儲存庫保留。曾由 Toolkit 停用的獨立連線會依安裝前設定還原。
- 設定與移出的 Rhino 外掛備份到 `%LOCALAPPDATA%\McpToolkitBackups\uninstall-*`。被修改或無法確認歸屬的外掛保留，並在結果及備份紀錄說明。
- 解除安裝不需要重新下載安裝包。移除後請重新啟動 Codex，卸載既有連線程序。

## 驗證範圍

更新測試涵蓋 Beta 篩選、通知去重、跳過與手動檢查、斷線、錯誤雜湊、安裝位置交接、啟用設定保留及失敗還原。解除安裝測試涵蓋非 Toolkit 路徑拒絕、相鄰文件保留、已修改 Rhino 外掛保留及自有外掛備份移除。完整測試結果另見 `docs/validation.md`。
