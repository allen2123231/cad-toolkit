# MCP Toolkit 0.4.1-preview.1

本版修正安裝位置、圖示、關閉軟體後的狀態，以及 AI 啟動 CAD 的流程。

## 安裝與更新

- 新安裝預設資料夾為 `%LOCALAPPDATA%\McpToolkit`，安裝頁可直接編輯路徑或按「瀏覽」。完整安裝從舊 `CadToolkit` 路徑開啟時，也預選新名稱；單項修復仍使用目前位置。
- 引擎、三套獨立環境及 Plugin 設定都使用選定位置。安裝到新位置不會自動刪除舊資料。
- 安裝程式與常駐程式使用獨立入口；舊版常駐時仍會顯示新版安裝畫面。取消不會關閉舊版。按下安裝後才重新啟動 Toolkit，保留 CAD 程序及文件。
- 工作列及通知區採用 16–256 像素的多尺寸圖示。原本 48 像素圖示內只有 16 像素寬的圖案，本版原生視窗圖示的圖案寬度為 48 像素。

請將 `McpToolkitSetup.exe` 與 `cad-toolkit-payload.zip` 放在同一資料夾，執行安裝並選擇位置。完成後重新啟動 Codex，讓新的 MCP 啟動工具與使用指引生效。這份預覽包先在本機交付，尚未發布 GitHub Release。

## 狀態與啟動

- 「可以使用」必須同時具有可見的軟體主視窗及通過身分核對的 MCP 連線。只有背景程序、隱藏視窗或舊文件快取不算可以使用。
- 視窗關閉或重新開啟時，清除舊就緒狀態與文件資訊；檢查尚未完成時顯示正在檢查。
- 三套 MCP 都新增 `open_application` 與 `get_application_state`。以正常可見方式啟動，既有主視窗被隱藏時會恢復顯示；啟動或授權等待中不重複開程序。視窗出現後仍須等待各自 MCP 橋接就緒。
- Rhino 的要求選窗工具會自動開啟／恢復 Rhino，再讓使用者選窗。沒有視窗時，選窗面板顯示啟動進度。選定後繼續取得原對話綁定，不必另外手動開 Rhino。
- 安裝後保留自動載入流程，不需要輸入 `mcpstart` 或 `APPLOAD`。

## 本機驗證

- 76 項 Python 測試、27 項 WPF 檢查、桌面問題重現檢查及 4 項打包後 Rhino 防誤操作測試通過。
- 實際安裝三套環境到 D 槽中文資料夾，使用隔離 Codex 設定執行三套產生的 MCP 啟動設定，工具數為 Rhino 78、AutoCAD 10、Inventor 38。使用者原設定雜湊不變。
- AutoCAD 2026、Inventor 2027 首次可見啟動後，分別取得 file_ipc／COM 唯讀狀態。
- 重現參考對話留下的隱藏 Rhino 主視窗，由新連線要求恢復原程序，使用實際選窗按鈕取得綁定及唯讀文件資訊；沒有增加 Rhino 程序，沒有建立或修改物件。
- 實際管理畫面原先有兩套就緒；正常關閉測試用 Inventor、AutoCAD 後只剩仍開啟的 Rhino 就緒，舊文件不再顯示為可用。
- 舊版常駐時，實際開啟新版安裝程式，確認版本、預設新資料夾及可編輯路徑，取消後舊版仍正常執行。沒有藉此測試覆寫使用者目前的安裝。

EXE 尚未簽章；乾淨 Windows、其他 CAD 版本及真人新手測試尚未完成。AutoCAD／Inventor 仍只支援視窗清單、命名及定位，尚未開放各視窗的獨立對話路由。
