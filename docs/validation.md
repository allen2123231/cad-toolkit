## 0.6.1-beta.1 AutoCAD 受控連線與中斷恢復（2026-11-21）

強化通知與原生被動狀態回報（A＋D），新增原生文件識別、持久化結果不明紀錄與恢復屏障。CAD 關閉、逾時、通知失敗或等待輸入時，後續繪圖要求仍可收到但回覆未執行；重新開啟並由使用者確認圖面後，必須重新提出操作。遲到通知也會被原生端拒絕。沒有導入自動補做繪圖的佇列。

146 個 Python 回歸、32 項一般桌面與 8 項恢復面板檢查通過；另完成 3 項真實 MCP stdio 啟動與缺少原生識別時不派送的檢查。涵蓋通知卡住、傳送失敗、OS 鎖占用、MCP 程序終止、舊 pending、孤立收件、損壞 JSON、模態／忙碌、程序建立時間與持有已終止程序控制代碼、過期文件確認、既有其他 CAD 冒充重開目標，以及等待啟動期間仍可接收恢復查詢。兩張恢復面板截圖使用固定測試資料，非 CAD 實機畫面。

獨立完整 AutoCAD 2026 程序完成 27 項原生實機檢查：確認空圖面並存檔、錯誤文件識別拒絕、同時第二批被擋、執行階段可觀察、部分修改後結束程序、重開圖面及確認、延遲回覆不解除屏障、通知遲到不執行、LINE 等待輸入轉入恢復，以及原有使用者主視窗保留。本次中斷回報約 1.28 秒；重開後仍只有原有 1 個圓，明確新操作才增加至 2 個圓，遲到通知與被擋的操作未增加圖形。該時間並非保證值，也不能復原尚未存檔的 CAD 工作。

實機使用 Windows 訊息收件驗證共用原生橋接，不代表 LT 2027 或完整版 COM 派送已完成完整實機驗收。LT 專用傳送分支、無外部 COM 限制及故障處理有自動測試；LT 2027 的安裝、自動載入及完整操作仍需另機驗證。AutoCAD 多視窗對話綁定與完整優先排程尚未完成。

本版已依使用者要求以未簽章 Beta 公開發布至 `v0.6.1-beta.1`，未更改後續版本的預設簽章門檻。正式發布前另通過 28 項更新／移除、10 項更新介面、更新進度回饋、MCP 管理／背景刷新及 4 項打包後 Rhino 保護檢查；包內 3,051 個檔案雜湊核對通過，確認新版原生識別、恢復通道與可獨立匯入的產生後 relay 已打包。發布後未登入的公開下載完整取得 setup 與 payload，大小及 SHA-256 符合發布清單；實際 Toolkit CheckUpdate 以 0.5.0-beta.1 及 0.6.0-beta.1 為版本比較輸入，均找到 0.6.1-beta.1。沒有執行使用者目前安裝的更新。
