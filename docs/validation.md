## 0.2.0-preview.2 完整流程實作（2026-09-16）

- 32 項 Python 測試通過，涵蓋既有生命週期、新增 Plugin 獨立步驟，以及 Inventor 首頁連線的應用程式身分檢查。
- WPF 渲染驗證 16 個頁面 × 96／144／192 DPI，共 48 張畫面；涵蓋桌面與 640×540 邏輯尺寸，檢查主要操作可及性、鍵盤焦點與歷史狀態。這不是實體螢幕 DPI 或真人可用性測試。
- 六張內建真實截圖可以從 EXE 資源載入；已檢視公開圖片不包含帳號、最近文件列表或工作檔名標題。
- C# 網路中斷、SHA-256 不符與取消保留原檔，重試使用驗證後資料。相鄰離線套件解壓與逐檔雜湊檢查通過。
- 七種非空組合完成實際隔離安裝；使用 `install --defer-plugin` 準備元件，再呼叫 `configure_plugin`。重複安裝沒有重建已完成環境。
- 三套一起安裝時在元件完成邊界中斷並續作通過。各組 AutoCAD／Inventor／Rhino 工具數仍為 8／36／70。
- 七組測試使用隔離 CODEX_HOME 和實際 Codex Plugin 指令，新元件全部保持停用；使用者原始 config.toml 雜湊前後相同，CAD 呼叫數為 0。
- 官方 Plugin 檢查器與六套 Skill 格式檢查通過。舊 UI schema 1 的連線／練習步驟可遷移到 schema 2；engine state.json 保持不變。

本次驗證不包含真實 CAD 端修改、切換目前使用者的連線、乾淨 Windows 或真人新手測試。Inventor 無文件通過條件已由單元測試驗證，仍需另行完成實機首頁情境驗收。
