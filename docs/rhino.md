# 安裝 Rhino 外掛，自動連線

在新安裝介面選擇 Rhino MCP，程式會自動完成連線設定。

## 操作位置

完整管理 → 安裝與版本 → 安裝／修復 Rhino MCP

固定採用本分支 RhinoMCP 0.5.3，已驗證自動橋接、每段對話獨立選窗、文件切換保護與雙視窗圓柱建模。Toolkit 完整乾淨 Windows 流程仍待驗收。

![MCP Toolkit 新安裝介面實際渲染](images/mcp-install.png)

## 只有第一次或更新外掛時

1. 安裝會自動準備完整原生套件，不必拖曳 RHP。
2. 已開啟時先自行儲存並重開；之後不需輸入 mcpstart。
3. 服務與外掛版本必須配對，版本不符會顯示在狀態面板。

## 依序操作

### 1. 安裝 Rhino MCP

操作位置：完整管理 → 安裝與版本 → 安裝／修復 Rhino MCP

在安裝與版本頁選擇 Rhino MCP，按「安裝所選 MCP」。必要環境、外掛及 AI 工具設定一起完成。

完成後：必要環境與連線設定已準備。

### 2. 開啟 Rhino

操作位置：Toolkit 的「開啟 Rhino」

開啟 Rhino。若安裝時已開啟，請先自行儲存並重開一次，再開啟要使用的文件。

完成後：軟體已正常開啟；授權／登入確認完成。

### 3. 自動連線

操作位置：右下角 MCP Toolkit 狀態面板

查看右下角 MCP Toolkit 狀態。檢查通過後自動啟用；到 Codex 開啟新對話即可使用。

完成後：檢查顯示橋接已連線與文件摘要，而且外掛與伺服器版本相符。


## 完成後會看到

檢查顯示橋接已連線與文件摘要，而且外掛與伺服器版本相符。

## 常見問題

- 找不到軟體：先安裝自己的 Rhino 並完成合法授權。
- 尚未連線：在安裝與版本頁按安裝／修復；若外掛正在使用，先自行儲存並重開軟體。
- 多個視窗：Rhino 可在管理視窗選擇目標；其他軟體請先確認唯一目標。Toolkit 不會替你關閉文件。

## 自選練習：Rhino：一個方塊

在 Rhino 新增空白模型，選擇毫米範本。先保存或保留原工作文件，避免覆寫。

貼到 Codex：

> 先確認目前是我新建的空白 Rhino 練習文件，單位為毫米；如果不是請停止。在原點建立 20 × 20 × 20 mm 的封閉實體方塊，確認尺寸、有效性與封閉狀態。不要修改其他文件，也不要自動儲存。

預期結果：一個 20 mm 方塊，AI 回報幾何有效且為封閉實體。

確認結果後，以 Rhino「另存新檔」存成 CAD練習_方塊.3dm。
