# Native application and document icons

These PNG assets preserve the icons supplied by the installed applications and their Windows document associations. Application and file icons are intentionally separate.

- Rhino 8: application resource 0; `.3dm` document resource 1.
- AutoCAD 2026: application resource 0; `.dwg` association from `acadficn.dll` resource 51; `.lsp` from resource 90.
- Inventor 2027: application resource 0; `.ipt` document association from `SrvRes.dll` resource 0.
- File Explorer: installed Windows Explorer application resource.
- Codex: the installed OpenAI desktop package's unplated application logo asset.

The assets are used to identify the respective software and document types in this Windows MCP Toolkit interface. Product names and icons belong to their respective owners. MCP Toolkit uses the blue plug mark requested for this application, following the geometry of RhinoMCP's tray mark.
